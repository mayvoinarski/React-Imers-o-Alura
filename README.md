# 🎶 Spotify Clone

O **Spotify Clone** é um projeto desenvolvido em React com o objetivo de replicar a interface e algumas funcionalidades básicas do Spotify. O foco está em criar uma experiência de usuário moderna e responsiva, com navegação fluida e design inspirado na plataforma original.

## 🎯 Objetivo do Projeto
- Praticar desenvolvimento com React e componentização
- Reproduzir a interface do Spotify com precisão
- Utilizar gerenciamento de estado e roteamento com React Router
- Tornar o site totalmente responsivo para diferentes dispositivos

## 🛠️ Tecnologias Utilizadas
- React.js
- HTML5
- CSS3 
- Json.server
